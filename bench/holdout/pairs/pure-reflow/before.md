# Notebook: hard-wrapped session

The session opened with the plain checklist and closed with the long
retrospective. We kept the wrap at seventy-two columns because the
terminal in the reading room cuts at eighty, and a margin keeps the
diff readable when the line endings change hands.

The retrospective ran long. Notes from it sit in the second block
below, rewrapped as one paragraph per line so the words carry no
wrapping history at all. Reading the two forms side by side is the
point of this pair: the text stays identical, and only the line breaks
move. A reader must still be able to see that nothing was rewritten,
while a diff must still account for every changed line.
